(Part 2/2 : the cerebellum), Addendum 'Random connectivity examined'. doi:10.5281/zenodo.17613147 · Other live demos of Part 2: demo 4-1 (Fig. 16), demos 80–83 (Figs. 7 and 8)

Every timeslice of the A-path is assumed to be affected by a set of granule cells large enough to contain all input permutations. The program lists all permutations, lists them again after 'ordering' (for the granule cell only the combination of its inputs matters), counts the right addressings (RAs) and wrong addressings (WAs) with the RA ratio, and shows how many permutations cause a given number of WAs.
